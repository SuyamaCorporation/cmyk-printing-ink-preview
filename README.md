# 08 - CMYK 印刷 インク 色 プレビュー

**ビルド日**: 2026-11-02
**カテゴリ**: practical
**slug**: cmyk-printing-ink-preview

## 概要

CMYK4色インクの混合シミュレーションと印刷色プレビューツール。Web表示と印刷近似色の比較が可能。

## 機能

- C/M/Y/K各スライダー（0-100%）
- CMYK→RGB変換（標準式）
- 印刷近似色（ドットゲイン15%シミュレーション）
- Web vs 印刷色の並列プレビュー
- インク総量300%超過時の警告
- HEX入力からCMYK逆変換
- 10種のプリセット（プロセスカラー・特色等）
- Canvas棒グラフでインク量視覚化（制限ライン表示）

## 技術仕様

- 単一HTMLファイル、Tailwind CDN使用
- CMYK↔RGB双方向変換の純粋JS実装
- ΔE（RGB空間近似）による色差表示
